File Structures

Understanding how data is organized and accessed in storage systems

Definition

A File Structure is a combination of:

  • Data Representation: How data is organized within files
  • Operations: Methods for accessing and manipulating data

This combination enables applications to efficiently store, retrieve, and manage data.

Core Operations

// Fundamental file operations
Read - Retrieve stored information
Write - Insert or add new data
Modify - Update existing records
Search - Find specific data based on criteria
Traverse - Read data in a particular order

File Structure Examples

Different approaches to organizing data in files

Sequential Files

Data is stored one record after another in a linear fashion.

Characteristics:

  • Simple implementation
  • Efficient for sequential processing
  • Inefficient for random access
  • Access time proportional to file size

Use Case: Log files, backup archives

Indexed Files

Uses an index structure to quickly locate records.

Characteristics:

  • Fast access to specific records
  • Additional storage for index
  • Index maintenance required
  • Efficient for search operations

Use Case: Database systems, library catalogs

Hashed Files

Uses a hash function to determine storage location.

Characteristics:

  • Very fast direct access
  • Potential for collisions
  • Efficient for equality searches
  • Performance degrades with poor hash function

Use Case: Dictionaries, symbol tables

Tree-Structured Files

Organizes data in a hierarchical tree structure.

Characteristics:

  • Efficient for range queries
  • Balanced trees maintain performance
  • Complex implementation
  • Examples: B-trees, B+ trees

Use Case: File systems, databases

Memory Hierarchy & Access Times

Understanding the performance implications of different storage types

Memory Hierarchy

Computer systems use a hierarchy of storage types to balance speed, cost, and capacity:

  • CPU Registers - Fastest, smallest
  • Cache - Very fast, small
  • Main Memory (RAM) - Fast, medium size
  • Secondary Storage (SSD/HDD) - Slow, large capacity
  • Tertiary Storage (Tape) - Very slow, massive capacity

Key Insight: Disk access is ~100,000x slower than RAM access, making disk I/O the primary performance bottleneck.

Primary Course Objective

Optimizing file structures to minimize disk access

Minimizing Disk I/O

The main goal of file structure design is to minimize the number of disk accesses required to retrieve or update data.

Strategies for Optimization:

  • Locality of Reference: Group related data together
  • Buffering: Read data in blocks rather than individual records
  • Indexing: Create efficient lookup structures
  • Caching: Keep frequently accessed data in memory
  • Compression: Reduce physical I/O by storing more data per block

History of File Structures

Evolution of data storage and access methods

Timeline of Development

1950s
Magnetic Tapes - Sequential access only, access time proportional to file size
1960s
Direct Access Storage - Disks enabled random access, leading to indexed files
1970s
Tree Structures - B-trees (1972) and B+ trees provided efficient disk-based indexing
1980s
Dynamic Hashing - Extendible and linear hashing provided efficient file growth
1990s-Present
Modern File Systems - Journaling, compression, encryption, and distributed file systems

File Management

Organizing and maintaining computer files effectively

File Organization

File Management encompasses procedures for organizing computer files to improve accessibility and efficiency.

Key Concepts:

  • File Path: The complete location of a file (e.g., C:\Users\Documents\file.txt)
  • Root Directory: The top-level directory of a storage device
  • Subdirectories: Folders within other folders for organization
  • File Extension: Identifies file type and format (.txt, .jpg, .exe)

File Management Utilities

Operating systems provide file management tools:

  • Windows: File Explorer
  • macOS: Finder
  • Linux: Various file managers (Nautilus, Dolphin, etc.)

Common Operations:

  • Create, rename, move, copy, delete files
  • Create and organize folders
  • Search for files by name, type, or content
  • View file properties and metadata

File Naming & Formats

Standards and conventions for file organization

File Naming Conventions

Different operating systems have specific rules for file names:

Windows:

  • Max 255 characters for path + filename
  • Case insensitive
  • Reserved characters: \ / : * ? " < > |
  • Reserved names: CON, PRN, AUX, NUL, COM1-9, LPT1-9

macOS:

  • Max 255 characters
  • Case sensitive (by default)
  • Reserved character: : (colon)

File Formats

The internal organization of data within a file:

Common Categories:

  • Text: .txt, .docx, .pdf, .html
  • Images: .jpg, .png, .gif, .bmp
  • Audio: .mp3, .wav, .aac, .flac
  • Video: .mp4, .avi, .mov, .mkv
  • Executable: .exe, .app, .bat, .sh
  • Data: .csv, .json, .xml, .db

File formats typically include:

  • Header: Metadata about the file
  • Data: The actual content
  • Footer/EOF marker: End of file indicator
